# Coaching with Katrina

A modern, responsive website designed and developed for **Katrina**, a Life and Career Coach.

The website presents Katrina's coaching philosophy, services, experience, values, testimonials, and resources, while providing visitors with a clear and welcoming way to learn more and get in touch.

## 🌱 About the Project

**Coaching with Katrina** was created to build a professional online presence for a Life & Career Coaching practice.

The goal was to create a website that feels:

* Professional and trustworthy
* Warm and welcoming
* Personal and authentic
* Easy to navigate
* Accessible across different devices

The website combines informative content with a clean, calm visual experience suited to the coaching and personal-development space.

## ✨ Features

* 🏠 **Home Page** - Introduction to Katrina and her coaching approach
* 👩‍💼 **About Page** - Background, experience, and coaching philosophy
* 💼 **Services** - Overview of coaching services
* 🌱 **Life Coaching** - Dedicated information about life coaching
* 🏢 **Corporate Coaching** - Coaching services focused on professional and corporate contexts
* 🧘 **Meditation & Breath Work** - Information about meditation and mindfulness
* 📝 **Blog** - Articles and personal-development resources
* 💬 **Testimonials** - Client experiences and feedback
* 📩 **Contact Page** - A way for visitors to connect with Katrina
* 📱 **Responsive Design** - Designed to work across desktop, tablet, and mobile screen sizes

## 🛠️ Technologies Used

* **HTML5** - Page structure and semantic markup
* **CSS3** - Styling, layouts, responsiveness, and visual design
* **JavaScript** - Interactive functionality and dynamic behaviour
* **Git & GitHub** - Version control and project management

## 🎯 Project Goals

The main objectives of the project were to:

1. Establish a strong and professional digital presence for Katrina's coaching practice.
2. Clearly communicate her coaching services and areas of expertise.
3. Make information easy for potential clients to discover.

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/cabluemgeek/Coaching-with-Katrina.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd Coaching-with-Katrina
```

### 3. Run the website

Open `index.html` in your browser.

For development, you can also use an extension such as **Live Server** in VS Code for a better development experience.
